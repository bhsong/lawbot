# 캘린더 입법예고 검토 대기 목록 검증

- 개발 DB를 읽기 전용으로 조회했다. **보류 목록 → 시행일 보류**는 5건, **입법예고 검토 대기**는 0건을 반환했다. 예고 시작·종료 일정 224건을 다시 확인했다. Chromium 390px·1280px에서 두 종류의 건수, 대기 목록이 비었을 때의 안내와 닫은 뒤 포커스 복귀를 확인했다.
- 대기 건이 있는 시험 DB에서는 의안번호, 누락된 날짜 확인 사유, 공식 링크가 표시됐다. API에서 최신 대기본만 페이지로 반환하고 승인·반려·철회한 예고와 별도 법률안을 제외하는 것을 확인했다. 승인한 예고는 대기 목록에서 빠지고 날짜별 일정에 표시됐다.

| 검증 | 결과 |
|---|---|
| 단위·계약·통합·대역 E2E (`PYTHONPATH="$PWD/services/law-calendar/src" .venv/bin/python -m pytest -q`) | 906개 통과, 기본 선택에서 제외 13개 |
| 캘린더·챗봇 프런트엔드 타입·Vitest·빌드 | 통과, Vitest 각각 19개 |
| Ruff, 포맷, 두 Pyright 범위, API 스키마, Python 문법, 두 uv 잠금 파일 | 통과 |
| 실제 모델 E2E·모델 스모크·품질 평가 | 실행 안 함 |
