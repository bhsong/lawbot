## 재현과 수정 확인

- Red에서 시행령의 제목이 달라지거나 원천 경로가 사라져도 조문 생성은 성공했다. 같은 누락을 실제 CSV 모드 `lawbot-articles-update`에 입력하면 `updated=yes`와 종료 코드 1로 끝났고, 시행령이 빠진 CSV를 활성화했다.
- Green에서 필수 시행령 제목 변경, 경로 삭제와 같은 제목의 유효 후보 2건은 해당 문서명과 함께 실패했다. 하위법령을 선언하지 않은 합성 법령은 본법을 생성했다. 그 법의 시행규칙을 선택 조문 CSV에 직접 넣으면 원천 문서 부재로 실패했다.
- 같은 누락의 CSV 자동 갱신은 `articles updated=no error=시험법 시행령:`으로 시작하는 결과 줄과 종료 코드 2를 반환했다. 임시 활성 CSV·매니페스트는 바이트 단위로 보존됐다. 아카이브나 스테이징 파일이 생성되지 않았고 검색기 생성·웹 재시작 호출은 0회였다.
- 로컬 개발 Legalize KR `bcb7aea778`의 기준일 2026-11-03과 2026-11-10 각각에서 등록된 법률 17개, 시행령 17개, 시행규칙 16개에 대응하는 원천 파일을 하나씩 찾았다. 농어촌특별세법의 하위법령은 시행령만 등록했다.
