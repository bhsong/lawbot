## 확인한 동작

- 스크립트: PATH의 가짜 `launchctl`·`uv`·`date`와 임시 `.env`를 사용했다. 시간 분기, 명시 옵션 우선과 상속 변수 무시, 키 누락·빈 값, 잘못된 구분자에서 등록 상태 불변, 한 서버만 등록된 야간 정지, 주석이 붙은 마지막 중복 키 적용, 다른 키의 명령 미실행과 값 미노출을 확인했다.
- 예약: `RunAtLoad`와 매시 정각·30분, 같은 상태에서 bootstrap·bootout·준비 확인·로그 0건을 확인했다. 첫 예약의 운영 시작 + 25분 마감, 다음 예약 경계 직전 상한, 늦은·수동 시작의 단일 확인, 자정 첫 기동과 자정 이후 별도 예약의 재판정을 검증했다. 대기 중 `.env`를 다시 읽지 않고 다음 `apply`에서 변경을 적용했다.
- 웹앱: 동일 mtime·크기의 파일을 원자 교체해도 다음 질문에서 마지막 중복 키의 운영 시간을 표시했다. 형식 오류는 직전 안내를 유지하며 한 번만 경고했다. 일시적 파일 열기 실패는 같은 경고를 반복하지 않고 다음 질문에서 재시도했다. 시작 환경 변수(빈 값 포함)는 파일 변경 후에도 우선했다.

## 대역 E2E 질문·응답

같은 웹앱 프로세스와 로그인 세션에서 첫 질문에 답한 뒤 임시 `.env` 한 줄을 바꾸고 두 번째 질문을 보냈다. 다음은 최종 실행의 상담 기록 원문이다.

1. 질문: `해고 예고 없이 갑자기 해고되면 어떻게 하나요?`

   ```text
   가짜 모델 답변입니다. 근로소득 세금, 4대보험

   근거: 소득세법 제95조(양도소득금액과 장기보유 특별공제액)
   ```

   대역 응답의 인용: 소득세법 제95조. 품질 점수는 산정하지 않았다.
2. 질문: `주 40시간 일하면 주휴수당은 얼마인가요?`

   ```text
   답변 서비스 운영 시간은 14:00–15:00입니다. 운영 시간에 다시 질문해 주세요.
   ```

   화면과 상담 기록이 일치했다. `error_type=off_hours`, `delivery_status=sent`, 피드백 버튼 없음, 모델 호출 0건. 조문 인용·품질 점수 해당 없음.

운영 트리·실제 launchd·운영/개발 `.env` 미접근. 운영 반영, 실제 모델 E2E, 모델 스모크, 품질 평가: 실행 안 함.
