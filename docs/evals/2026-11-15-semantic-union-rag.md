## 보충 데이터와 커버리지

PR 2의 개발 DB를 복제한 뒤 코퍼스 `v5-live-2026-11-03`에서 확인했다. 입력 60행 모두 현재 조문 버전 해시와 일치해 12개 조문에 답변 없는 원자와 질문을 승인했다. 해시 불일치·누락, 계산 질문, 보호 질문 정규화 일치·근접 중복, 기존 질문 중복은 각각 0건이다. 동일 파일 재실행으로 승인·감사가 중복되지 않는다. 승인 감사에 actor `import`, 사용자 승인 사유와 출처 SHA-256을 보존했다.

| 노동 v4 split | 문항 수 | 정답 조문 수 | 승인 원자가 있는 정답 조문 수 | 정답 조문이 덮인 문항 | 보충 조문 문항 |
| --- | ---: | ---: | ---: | ---: | ---: |
| val | 1,110 | 414 | 414 | 1,110 | 22 |
| test | 2,075 | 415 | 415 | 2,075 | 60 |

커버리지에는 v4 `split_emb`의 노동 법률 A·B 행에서 ID와 정답 조문만 읽었다. 보충 질문 원문, 보호 문항 원문, 답변은 기록에 포함하지 않는다.

## 실제 평가 계획

커버리지 통과 뒤 각 단계의 설정과 코퍼스·인덱스 지문을 대조한다. 노동 val에서 atomic K 20·50을 비교하고, 그 다음 union 추가 예산 5·10을 비교한다. R@3, MRR, 예산이 작은 순으로 선택한다. 법률 리랭킹 R@3는 [기존 v6 기록](2026-11-14-v6-stage4a-eval.md)과 같이 정답 조문이 리랭킹 상위 3개에 들어간 문항 비율이다. 세금·보험 대조군은 그 평가와 같은 법률 정답 범위이며 test 1,445건이다.

시맨틱 val은 2,424개 라벨 행과 고유 입력 1,797개다. `not_reusable` 오적중, 다른 답변 오적중, `uncertain` 적중을 차례로 최소화하고, 그 안에서 `reusable` 적중을 최대화한다. 재사용 가능 라벨 중 누락한 건수와 실제 생성 절감 0건을 따로 기록한다. 노동 v4 train에서 뽑은 시맨틱 val 문장이 v6 임베딩 학습에 쓰인 경우가 있어 재사용 결과가 낙관적일 수 있다.

시간은 기존 v6 법률 리랭크 평균 2.66초와 PR 2 질문 임베딩 기록을 바탕으로 추정했다. 큰 후보 배치와 운영 부하에 따라 달라진다. 단계당 동시 1, 자동 재시도 0, 생성 0, 06:20–06:50 KST 회피를 적용한다. 검색 단계별 조문 임베딩 1회는 표에 포함했다. 시작·종료 모델 revision 확인은 추론 요청 수에 포함하지 않았다. 실제 인덱스와 평가는 PR 이후 별도 승인 대상이다.

## 검증

- `uv run python -m lawbot.semantic_tools supplement`, `uv run python -m lawbot.semantic_eval coverage|plan`을 개발 사본에서 확인했다. 각 도구에 `--cache-db`, `--corpus-db`를 지정한다. 보충 적재에는 `--bundle`로 승인한 JSONL을 지정한다.
- 대역으로 승인·보호 검사·검색 전용·커버리지 차단, 합집합 후보 보존·본문 충돌, 리랭크 점수 계약과 장애, 시맨틱 shadow 평가와 val 순서, 기본 웹 응답·SSE·요청 로그 회귀를 확인했다.
- `uv run pytest -q` 기본 실행은 단위·계약·통합·대역 E2E를 포함해 2,105건 통과, 13건 제외다. `ruff check`, `ruff format --check`, `pyright`, Python 컴파일 검사도 통과했다. 챗봇과 법령 캘린더의 프론트 타입 검사·단위 테스트(55건·31건)·빌드를 통과했다.
- 실제 모델 E2E·모델 스모크·평가는 실행 안 함. 실제 모델 요청 0회. 검색 R@3·R@1·MRR, 지연, win/loss, calibration 값은 실제 모델 평가 후 기록한다.
