# v6 임베딩 재학습 Colab 결과 (2026-11-13~14)

v5b 모델에서 이어 학습했다. 데이터는 기존 질문을 검토해 고친 세트와 신규 조문 질문 31,500개다. 선택한 에폭은 2에폭이다. 임베딩 검색은 세금·보험과 신규 조문에서 크게 좋아졌다. 하지만 Colab 리랭킹에서 **노동 법률 R@3이 −1.5p**(95.9% → 94.4%) 내려갔다. 사용자 결정으로 v6(2에폭)를 맥 미니 4단계 A로 측정한다. 노동 비중을 높인 재학습(v6b)은 컴퓨팅 유닛 사정으로 이번 달 말에 한다. [계획](../plans/v6-embedding.md)

### 노동 법률에서 빠진 31문항

| 원인 (v6 top3 기준) | 건수 |
| --- | ---: |
| 같은 법의 다른 조문이 위로 | 18 |
| 세금·보험 조문이 top3에 끼어듦 (고용보험법 6, 국민연금법 4, 보험료징수법 2 등) | 9 |
| 다른 노동법 조문이 위로 | 4 |

31문항 중 19문항은 정답이 임베딩 후보 10개 밖으로 밀렸다. 예: "탄력근로 정산 어케하는거에요?"(정답 근로기준법 제51조의3 → 제51조·제51조의2·제52조), "한 달에 최소 몇 번은 정해진 날에 보수가 나와야 하나요?"(제43조, 후보 밖).

원인 추정 (측정하지 않음):
- 노동 문항의 학습 비중이 줄었다. v5b는 train 14,413개 중 약 43%였고, v6는 30,089개 중 6,280개(21%)다.
- 노동 질문의 negative_2 중 2,006개(32%)가 세금·보험 조문이다. 같은 노동법 안의 조문을 구분하는 연습이 줄었다.
- 에폭 선택 기준(노동 법률 MRR@10)이 리랭커 후보 진입(R@10) 하락을 잡지 못했다.

## 결정 (2026-11-14 사용자)

- **B: v6 2에폭을 맥 미니 4단계 A로 측정한다.** 기준은 11-11 신규 B 평가다(v5b, 같은 3,795조문, val 3,606).
- **A: 노동 비중을 높인 재학습(v6b)은 이번 달 말에 한다.** 규칙은 셋이다. ① 노동 train 문항을 2번 넣는다. ② 노동 질문의 negative_2는 노동 계열 조문에서 고른다. ③ 에폭 선택에 노동 법률 R@10 ≥ v5b 조건을 더한다. 컴퓨팅 유닛 사정으로 미룬다.
