# 관리자 인증 검증 (2026-11-08)

가짜 자격 증명, 가짜 모델과 임시 DB로 PR 6을 검증했다. [계획서](../plans/sqlite-admin-pipeline.md)

- 해시 왕복과 잘못된 형식 거부를 확인했다. 관리자 변수 누락·일반 계정과 같은 이름·DB 미설정을 시작 시 거부했다. 작은따옴표 안의 `$`를 `.env` 파서가 보존했고, 넓은 파일 권한을 경고할 때 해시를 출력하지 않았다.
- 관리자 설정이 있을 때 세션의 역할은 인증된 계정에서 결정됐다. 요청 본문에 넣은 역할은 결과에 영향을 주지 않았다. 관리자 미설정 시 로그인·`/api/me` 응답과 쿠키 동작을 유지했다.
- 로그인 실패 5회 뒤 429가 반환되고 15분 뒤 다시 로그인할 수 있었다. 많은 미등록 사용자명을 보내도 기록 개수에 상한이 적용됐고 관리자 잠금이 유지됐다.
- 관리자 로그인 성공·실패가 임시 DB에 남았다. 비밀번호·해시·쿠키·세션 ID는 기록되지 않았다. 감사 DB 쓰기를 실패시켰을 때 경고가 남고 로그인 응답은 유지됐다.
- scrypt 검증을 작업 스레드에서 지연시킨 동안 다른 사용자의 가짜 모델 채팅 스트림이 완료됐다.
- 관리자 역할·Origin·64 KiB 본문·세션당 분당 30회 제한은 라우트 없이 함수 단위로 확인했다. Chromium에서 기존 화면의 일반·관리자 로그인을 확인했다.
