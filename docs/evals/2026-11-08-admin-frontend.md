# 관리자 화면 검증 (2026-11-08)

PR 9를 개발 트리에서 임시 DB와 가짜 자격 증명으로 검증했다. [계획서](../plans/sqlite-admin-pipeline.md#pr-9--관리자-화면-featadmin-frontend)

- 서버 Red는 두 경고가 빠진 네 경우에서 실패했다. 수정 후 해시 우선, 버전 대체, `cleared` 제외, 기존 누출 경고와의 순서 및 상태 불변을 포함한 관리자 API 테스트 55개가 통과했다.
- Vitest는 역할 전환, 목록 로딩·빈 결과·401·403, 필터·커서, 경고 배지, 교정 입력·첫 포커스·Tab·Esc, 승격 실패 안내, 저장 중 버튼 비활성, 요청 재시도 키와 일괄 승격 결과를 확인했다. 캘린더 여섯 경로와 비교표 이미지 프록시 주소도 가짜 응답으로 확인했다.
- 기존 브라우저 헬퍼가 쓰던 `python -m lawbot.web`에서는 모듈을 두 이름으로 불러 관리자 예외 처리에서 `code`가 빠지는 경우를 재현했다. 헬퍼를 운영 문서와 launchd 템플릿에 명시된 `lawbot-app`으로 맞춰 관리자 오류 계약을 검증했다.

| 브라우저 폭 | 배치 | 공통 확인 |
|---|---|---|
| 390px | 캘린더 → 좋아요 → 문제 신고 | 페이지와 검수 다이얼로그 가로 스크롤 없음 |
| 1280px | 위 캘린더, 아래 좋아요·문제 신고 좌우 | 페이지와 검수 다이얼로그 가로 스크롤 없음 |

두 폭 모두 관리자 로그인 → 캘린더 미설정 안내 → 좋아요 검수 → 승격 → 목록의 `승격됨` 표시를 확인했다. 일반 계정으로 다시 로그인해 전환 메뉴가 없고 관리자 목록을 직접 호출하면 403임을 확인했다.
