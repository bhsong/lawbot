## 운영 반영

PR #142 병합 커밋 `c737919`를 `v5.8.1` 운영 worktree에 반영하고 `v5.8.2` annotated 태그를 게시했다. PR CI와 병합 커밋의 main CI가 성공했다. [PR #142](https://github.com/bhsong/lawbot/pull/142) · [main CI](https://github.com/bhsong/lawbot/actions/runs/43527294638) · [v5.8.2](https://github.com/bhsong/lawbot/tree/v5.8.2)

- 캘린더 서비스만 재시작했다. 06:30 통합 수집 등록, 웹앱과 모델 서버 프로세스, 운영 ERP 6건과 11월 14일 스냅샷 해시를 전후 대조했다. 법령 캘린더 상태, ERP v1·v2·상태 API 모두 HTTP 200이었다.
- 기존 성공 수집 기록을 확인한 뒤 운영 캘린더 DB에 이미 있는 의안만 새 검증 규칙으로 처리했다. 법률안 62건이 공개됐으며 당일 수집 26건을 포함한다. 발의·의결일 기준으로 DB의 공개 일정은 63행이다. 2026년 9~11월 날짜별 공개 API에서 총 56행이 조회됐다. 입법예고 승인 137건·대기 1건은 그대로다. 수집 재실행, 모델 추론, 메일 발송은 0회다.
- 배포 전 운영 캘린더 DB의 압축 복구본은 `services/law-calendar/data/rollback/v5.8.2/calendar.before.db`에 있다. 권한 `600`, DB v8, `quick_check=ok`, 외래 키 오류 0건, 대비표 이미지 테이블 0개를 확인했다. 코드 복구는 `v5.8.1`로 되돌린 뒤 캘린더를 재시작한다. 공개 승인 상태를 되돌려야 할 때는 배포 이후 변경 이력을 먼저 대조한 뒤 별도 데이터 복구 절차를 따른다.
