# v5 피드백 도구 검증 (2026-11-07)

PR 3에서 문항 정규화·중복 검사·최신 피드백 선택·검수 판정 매핑을 `lawbot.qa_rules`로 옮겼다. 검수·내보내기에는 레포 밖 임시 폴더의 합성 피드백만 썼다. [계획서](../plans/sqlite-admin-pipeline.md)

- 수정 전 기존 피드백 테스트 21개가 통과했다. 새 공통 규칙 테스트는 모듈이 없어 실행에 실패했다. v5 회귀 테스트 4개에서는 v5 누출 검사 누락, v5 조문 조회 실패, 혼합 기록의 프로필별 조문 조회 누락을 확인했다. 수정 후 기존 기대값을 유지한 채 피드백·공통 규칙 테스트 29개가 통과했다.
- 기존 보호 문항 목록의 내용과 순서를 `main`과 대조했다. v5 `split_emb` test 3,420개·val 2,052개와 추론 검증 30개가 추가됐고, v5 test와 일치하는 합성 피드백은 검수 CSV와 동반 JSONL에서 제외됐다.
- 혼합 v4·v5 내보내기에서 실제 v5 시행령 조문, 프로필마다 본문이 다른 합성 조문, 미지원 프로필 제외 건수를 확인했다. 현재 v4·v5 조합 CSV의 비삭제 조문 키 각각 812개·1,497개를 기존 인용 파서가 모두 인식했다.
