# 캘린더 숨은 보류 조문 20개 철회 (2026-11-17)

[계획](../archives/calendar-superseded-changes.md)

## 발견

운영 캘린더 DB에 `pending` 조문 20개가 공개 캘린더에도 관리자 보류 목록에도 나오지 않고 남아 있었다. 11-05~06에 같은 원문을 예전 파서(monitor-law-v1·v5)와 v6 파서로 두 번 가져오면서 생긴 행이다. v6은 조문을 항·호 단위 라벨로 나누고(예: `제110조` → `제110조 제1호`) 자동 승인했다. 옛 조 단위 행은 옛 수집본의 보류(사유 `complex`, 시행일 없음)로 남았다. 소속 이벤트 8개는 모두 승인 상태였고, 공개 조문 34개가 이미 나가 있었다.

## 반영 (사용자 승인 후 2026-11-17 13:20 KST)

- 백업: 운영 `services/law-calendar/data/calendar.db.pre-20261117-superseded.backup`(무결성 ok)
- 규칙: 승인된 이벤트에 속하고 현재 수집본(`event_sources.snapshot_id`)에 `change_versions`가 없는 `pending` 조문 → `withdrawn`, `verified_at` 비움, `held_changes` 삭제, 조문마다 `review_audit` 한 줄(reviewer `claude-review`, note `Superseded by current snapshot …`). 한 트랜잭션.
- 운영 DB 사본으로 먼저 실행해 같은 결과를 확인했다.
