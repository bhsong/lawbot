# 외부 접속 전환 전 출처 이용 조건 재확인 (2026-11-19)

캘린더와 챗봇을 Tailscale 밖(Cloudflare Tunnel + Access, 본인 계정만 허용)에서 접속하도록 바꾸기 전에 화면에 나오는 외부 자료의 이용 조건을 다시 확인했다. 접속자는 사용자 본인 하나이며, 일반 공개 배포가 아니다. 관리자 기능은 Tailscale 경로에서만 사용한다.

## 결론

- 기관 소식(ERP 드로어)은 현재 범위인 제목·게시일·공식 링크를 유지한다. 게시물 본문·첨부는 계속 저장·표시하지 않는다.
- 세 기관 저작권 정책의 출처 표시 조건과 고용노동부의 저작권정책 동시 링크 요청을 화면에 반영한다.
- 법령·행정규칙 원문은 저작권법 제7조의 보호받지 못하는 저작물이다. 원천 저장소의 메타데이터는 MIT이므로 출처를 표시한다.
- 이용 조건을 확인하지 못한 `mofe-qa`, `nts-forms`는 비활성을 유지한다.

- 국세청 정책 페이지는 길어서 앞부분 본문은 원문으로, 뒷부분은 요약으로 확인했다. 링크·제목·자동 수집에 관한 "없음" 판단 중 뒷부분은 요약 기준이다.
- 세 기관 모두 "제목 목록을 다른 사이트에 게시해도 된다"는 명시 문구는 없다. 현재 범위의 판단은 금지 조항이 없다는 점, 짧은 제목은 일반적으로 저작물로 보지 않는 점, 정상 게시물에 대한 링크라는 점에 근거한다. 법률 자문 결과가 아니다.
