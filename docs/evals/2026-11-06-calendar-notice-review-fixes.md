# PR #76 입법예고 리뷰 반영 검증

- 첨부 서버가 오류 HTML을 반환하는 경우를 재현했다. 수정 후 PDF를 열 수 없으면 수집 오류를 보고하고 저장된 주요내용과 대비표를 보존한다. 실제 PDF에 대비표가 없는 경우에는 해당 원문의 빈 결과를 저장한다.
- 이미 공개·보강한 151건을 동일한 수집 시각으로 구성했다. 첫 재수집에서 150건, CLI `--refresh --after-snapshot`으로 이어서 1건을 갱신했다. 직전 배치의 마지막 항목을 철회한 경우에도 같은 위치에서 이어졌으며 마지막 응답의 `nextAfterSnapshot`은 `null`이었다.
- 개발 DB를 읽기 전용으로 확인했다. 예고 주요내용과 대비표 각 112건, 대비표 539쪽, 날짜별 예고 일정 224건, 원문이 있는 시행 상세 60건, 시행일 보류 5건, 예고 검토 대기 0건이었다.
