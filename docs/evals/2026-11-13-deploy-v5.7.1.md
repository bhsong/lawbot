# 운영 반영 v5.7.1 (2026-11-13)

운영 worktree를 `6aae4f6`(`v5.7.0`)에서 원격 `main`의 `60d1142`로 갱신했다. 수집 설정 등록부 [#129](https://github.com/bhsong/lawbot/pull/129), 국회 입법예고 PDF 자동 다운로드·이미지 API 제거와 법제처 HTTPS 호스트 제한 [#130](https://github.com/bhsong/lawbot/pull/130)을 반영했다. 해당 커밋의 [main CI](https://github.com/bhsong/lawbot/actions/runs/43364382401)가 성공했다. 사용자 요청에 따라 패치 버전 [v5.7.1](https://github.com/bhsong/lawbot/tree/v5.7.1)을 배포 검증 후 원격에 게시했다.

## 복구 자료

운영 캘린더 데이터 디렉터리에 검증한 v8 백업과 이미지가 없는 `calendar.db.pre-v8.backup`이 있다. DB 장애 시 캘린더 쓰기 작업을 먼저 멈추고 백업의 `user_version`, `quick_check`, 외래 키, 대비표 이미지 부재를 확인한다. 동일 버전 복구에는 v8 백업을 사용한다. 배포 전 코드로 되돌리면 국회 PDF 자동 수집 코드가 돌아오므로 그 상태에서 정기 수집이 실행되기 전에 검토한다. [운영 절차](../operations.md#국회-입법예고-대비표-이미지-정리용-캘린더-db-v8)
