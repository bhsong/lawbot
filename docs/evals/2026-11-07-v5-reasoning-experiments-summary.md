# v5 법률 추론 개선 실험 요약

2026-11-07. v5의 별도 법률 추론 val 30문항과 새 합성 문항 6개에서 검색 근거 추가, 조문 배치, 프롬프트 변경을 비교했다. **기존 v5 구성을 유지한다.** 누락 근거를 정확히 보강하면 답변이 나아지는 사례가 있었지만, 실험한 자동 규칙과 프롬프트에서는 답변 하락도 관찰됐다.

## 기준선과 실패 단계

v5 기본 구성은 30문항 중 내용 일치 19건, 부분 일치 5건, 불일치 6건이었다. 기준 조문 전체 제공은 23건, 전체 인용은 20건, 거절은 2건이었다. 완료 시간은 검색을 포함해 평균 21.57초였다. [30문항 기준선과 답변 원문](2026-11-07-v5-legal-reasoning-val.md)

부분 일치·불일치 11문항 중 7문항에서 기준 조문이 빠졌다. 임베딩 후보 10개 밖에서 빠진 문항은 5개, 리랭킹 상위 3개 밖으로 밀린 문항은 3개였으며 한 문항은 두 단계에 겹쳤다. 나머지 4문항은 기준 조문을 모두 제공하고도 답변에서 조건이나 예외를 잘못 적용했다. [문항별 단계 진단](2026-11-07-v5-legal-reasoning-stage-diagnosis.md)

## 적용 판단

- **자동 검색 보강 보류.** 명시 참조를 넓게 따라가면 기준 조문 회수 증가에 비해 발동이 많았다. 1위 타법 정의 규칙은 발동이 적었지만 새 6문항에서 정답 수가 늘지 않았고, 중간정산 의무 질문의 ‘계산’ 표현에도 발동했다.
- **보강 조문의 인접 배치는 후보로 보관.** 같은 조문을 끝에서 관련 조문 바로 뒤로 옮긴 비교에서 2건 중 1건이 개선됐다. 배치 효과는 이 2문항에서만 따로 측정했다.
- **프롬프트 문장 추가 보류.** 프롬프트만 바꾼 비교에서 개선보다 하락이 많았고 생성 시간도 늘었다. 조문까지 함께 바꾼 결과에서는 각 변경의 기여를 분리하기 어렵다.
- **생성 오류를 별도로 추적.** 새 문항에서 올바른 조문과 계산 조건을 갖추고도 최종 숫자를 틀리거나 첫 줄과 마지막 줄에 서로 다른 금액을 냈다. 조문 제공, 인용, 내용 판정을 계속 구분한다.

질문·답변 원문, 인용 조문, 점수와 실행 구성은 각 평가 기록에 보존했다. [별도 30문항 Val](../../data/v5/qa_reasoning_val.csv)과 [전용 평가기](../../tools/lawbot-tools/src/lawbot_tools/eval_reasoning.py)는 회귀 검증에 사용한다. 후속 실험의 임시 실행기와 중간 데이터는 정리했다.
