# v5 자동 근거 보강의 오프라인 비교

추론 val 30문항은 기존 v5 실행의 법률·하위법령 순서를 그대로 사용했다. 일반 val은 Colab에 저장된 v5b 3에폭 검색 결과에서 법률 정답이 있는 노동 625문항과 세금·보험 622문항을 사용했다. 일반 val에는 문항당 기준 조문이 하나 있고, 다른 보완 조문의 관련성은 별도로 표시되어 있지 않다. [기존 추론 평가](2026-11-07-v5-legal-reasoning-val.md) · [v5b 검증](2026-11-07-v5b-evaluation.md) · [계획](../archives/reasoning-auto-supplement.md)

## 비교 방법

- 법률 원문에서 기존 파서로 같은 법령과 타법의 명시적 참조를 읽었다. 참조하는 쪽과 참조받는 쪽을 후보로 삼고, 질문과 조문 제목·본문의 문자 2~4그램 TF-IDF 코사인 유사도를 사용했다. 넓은 조건은 기존 근거 법률의 최대 유사도 대비 70%, 엄격 조건은 100%를 요구했다. 절대 유사도 하한은 0.04였다.
- 정의 조항에서 타법의 단일 법률 조문을 가리키는 정의를 추출했다. 해당 용어가 질문에 직접 나오고 기존 조문에 쓰였거나, 질문이 산정을 묻고 기존 조문에서 그 용어가 수량과 함께 쓰인 경우를 보강 후보로 삼았다.
- 각 후보는 연결된 기존 조문 바로 뒤에 삽입했다. 기존 조문의 상대 순서와 하위법령을 유지했다. 기준 조문과 문항 ID는 선택에 쓰지 않고 판정에만 사용했다.

일반 val에서 기준 조문이 이미 제공된 경우에도 보완 조문이 유용할 수 있다. 이 열은 추가 입력이 발생한 횟수이며 보강이 틀렸다고 판정한 수가 아니다.

1위 조문에서 타법 정의만 따르는 규칙은 두 추론 문항에서 평균임금 정의를 찾아 퇴직급여법 제8조 바로 뒤에 놓았다.

| 문항 | 자동으로 선택한 조문 | 앞선 답변 실험에서 관찰한 내용 |
| --- | --- | --- |
| ERR002 · 통상임금 인상과 퇴직금 | 근로기준법 제2조 | 해당 조문을 제공한 실험에서도 평균임금과 통상임금의 조건을 잘못 적용했다. |
| ERR007 · 마지막 달 월급으로 퇴직금 계산 | 근로기준법 제2조 | 해당 조문을 추가한 기존 프롬프트 실험에서 90일 고정 오류가 사라졌다. |

일반 val의 1위 정의 규칙은 퇴직금 중간정산 후 근속기간을 묻는 Q2761과 확정급여형 퇴직연금 일시금 기준을 묻는 Q2901에서 발동했다. 두 질문 모두 기존 기준 조문이 제공됐다. 1위 제한을 두기 전 발동한 퇴직소득세 문항 T00473은 세법 조문이 1위였고 퇴직급여법의 평균임금 정의는 3위 법률 조문에서 따라갔다.

추론 val의 누락 기준 조문 10개 중 7개가 명시적 참조 또는 정의로 이어졌다. ERR001의 누락 두 조문과 ERR016의 누락 조문은 기존 법률 조문에서 이 방식으로 연결되지 않았다. ERR012의 사용촉진 조문은 후보로 만들었지만 질문 유사도 기준을 넘기지 못했다. ERR021은 넓은 조건에서 두 기준 조문 중 하나를 회수했다. [기존 단계별 순위](2026-11-07-v5-legal-reasoning-stage-diagnosis.md)

## 시간과 판단

법령 참조와 정의를 미리 인덱싱한 뒤 저장된 검색 결과에 보강 후보를 고르고 순서를 정하는 로컬 P95는 일반 val에서 1위 정의 방식 약 0.005ms, 엄격한 참조+정의 방식 약 0.20ms였다. 생성과 전체 응답 시간은 측정하지 않았다. 이전 조문 보강 실험에서는 보강 대상의 생성 시간이 평균 약 6초 증가했다. [조문 보강 답변](2026-11-07-v5-reasoning-supplement-experiment.md) · [생성 시간 비교](2026-11-07-v5-reasoning-conditional-prompt.md#같은-기준으로-비교한-생성-시간)

명시 참조를 넓게 따라가는 규칙은 일반 val에서 189~388번 발동해 기준 조문 2~4건을 더 회수했다. 1위 법률 조문의 타법 정의만 따르는 규칙은 발동을 크게 줄였으나 추론 val의 회수 증가가 두 문항에 한정됐다. 1위 정의 방식은 한정된 검증 후보로 두고, 전체 적용 판단에는 기존 프롬프트에서 자동 보강의 답변 효과와 기존 답변 하락을 함께 확인한다.
