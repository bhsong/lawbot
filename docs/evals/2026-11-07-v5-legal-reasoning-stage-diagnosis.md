## 평가 도구 검증

- [PR #81 리뷰](https://github.com/bhsong/lawbot/pull/81#discussion_r4499807854)에서 지적한 사전 확인 HTTP 실패와 웹앱 초기화 예외를 재현했다. 평가기는 원래 예외 연결과 traceback에 실패 단계를 붙이고, 서버 주소와 토큰을 가린 뒤 표준 오류와 새 실행 폴더의 `failure.txt`에 기록한다. 질문 도중 실패한 경우 문항 결과에 요청 단계와 오류 유형을 남긴다.
- 초기 전체 실행에서는 평가기 호출 후 로그 수준이 복원되지 않아 리랭킹 로그 테스트 1건이 실패했다. 로그 수준을 복원한 뒤 `uv run --no-sync pytest -q`의 단위·계약·통합·대역 E2E 포함 기본 테스트 929개가 통과했다(선택 실행 13개 제외).
- Ruff 검사·포맷, Python 문법 검사, Pyright 두 프로젝트와 캘린더 API 스키마 검사가 통과했다. 실제 모델 브라우저 E2E와 모델 스모크는 실행 안 함으로 구분한다.
