# 개발 캘린더 입법예고 변경 내용 검증

| 개발 DB 확인 항목 | 결과 |
|---|---:|
| 주요 변경 내용이 있는 공개 입법예고 | 112건 |
| 공식 신·구조문대비표를 열 수 있는 입법예고 | 112건, 총 539쪽 |
| 시작·종료일 공개 일정 | 224건, 기존 API 결과와 동일 |
| 저장 Before/After 원문이 있는 시행 일정 | 60건, 기존 상세 API와 동일 |
| 법령 개정 보류 | 5건, 기존 목록 API와 동일 |

- 개발 DB 사본에서 의안번호와 예고기간을 대조한 뒤 국회 공식 상세와 법률안 PDF를 수집했다. 첨부 전체의 80쪽 제한 때문에 빠졌던 두 문서도 150쪽 한도에서 처리했다. 근로자퇴직급여 보장법안(2221787)은 45–104쪽, 지방세법안(2221926)은 29–77쪽에 대비표가 있다. 근로기준법안(2221981)은 7–10쪽이다.
- 시작·종료 일정 224개의 상세가 각각 같은 의안의 내용을 반환하는지와 대비표 이미지 539개가 PNG로 열리는지 API에서 확인했다. 위 3개 의안은 Chromium 390px·1280px에서 주요내용, 대비표 첫 장과 마지막 장, PDF 링크, 닫은 뒤 포커스 복귀를 확인했다.
- 개발 DB를 v5로 올리고 사본과 기존 데이터가 같은 것을 확인한 다음 본문·이미지 테이블만 추가했다. 마이그레이션 사본 `calendar-v5-verified.db.pre-v5.backup`을 보존했다. 실제 개발 DB에서 API 비교와 SQLite 무결성 검사를 다시 통과했다. 기본 수집 명령 재실행은 신규 0건, 실패 0건이었다.
