## PR #104 모바일 상세 이동 재검증

- Red에서는 390px에서 목록을 눌러도 상세 제목의 뷰포트 교차 비율이 0이었다. 실패 진단용 스크린샷은 확인 후 정리했다.
- 390px에서 상세 제목의 뷰포트·포커스, 목록의 원래 행으로 복귀, 동일 답변 재선택, 필터로 가려진 행의 목록 제목 복귀를 확인했다. 1280px와 새로고침에서는 상세 제목으로 자동 이동하지 않았다. 캐시 관리자 Chromium 시나리오 4개가 통과했다.
- `uv run --locked pytest` 1,221개 통과, 기본 선택 13개 제외, skip 0개. Ruff, Pyright, 문법·스키마 검사와 두 프런트엔드의 타입 검사, Vitest 37개·19개, 빌드가 통과했다.
- 실제 모델 E2E·모델 스모크·품질 평가는 각각 실행 안 함이다.
