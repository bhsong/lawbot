# 열린국회정보 수집과 법령 캘린더 연동 검증

- 실행일 2026-11-05 KST · 개발 브랜치 `codex/assembly-law-calendar` · 기준 `71e3739`
- 제22대, 제목 키워드 16개, 페이지당 1,000건으로 전체 목록을 읽었다. 실제 API 연결 테스트에서는 페이지당 2건을 요청했다. 테스트와 측정에는 개발 키, 임시 Monitor home, 임시 캘린더 DB, 루프백 브라우저를 사용했다.
- 운영 반영과 실제 모델 호출은 실행 안 함. API 명세와 초기 조사는 [검증 가이드](2026-11-05-assembly-api-validation-guide.md)에 있다.

실제 수집 시간에는 기존 법령 수집·챗봇 점검·모델 요약 시간이 포함되지 않는다. 실원천에서 동일 게시물의 진행→종료 전환은 관찰하지 못했다. 대역에서 진행 목록 누락, 종료 목록 확인, 원문 기간 재시도와 정정을 재현했다.

## 기본 실행 중 보완

- 기본 테스트를 샌드박스에서 시작할 때 MLX 초기화 중 프로세스가 종료됐다. 승인된 로컬 실행으로 다시 검증했다.
- 첫 로컬 전체 실행에서 예고 빈 상태 문구가 바뀐 뒤에도 옛 문구를 찾는 두 Chromium 테스트와, 새 법률안 카드에서 문구와 설명을 동시에 선택한 두 Chromium 테스트가 실패했다. 새 문구와 카드 버튼을 기준으로 대상을 지정해 수정했다.
- 첫 타입 검사에서 기본 수집기 목록이 Git 수집기 전용으로 추론됐다. 목록 타입을 기존 `Collector` 계약으로 선언하고 두 Python 검사 범위를 다시 확인했다.
