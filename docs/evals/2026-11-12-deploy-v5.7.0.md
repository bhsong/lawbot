## 피드 갱신

피드는 자동으로 갱신되지 않는다. 06:30 monitor 작업에 넣지 않았다. 원천이 바뀌었을 때는 운영 트리에서 아래 순서로 수동 갱신한다.

```zsh
cd ~/Work/lawbot-prod
E=(uv run --project services/erp-updates --frozen erp-updates --data services/erp-updates/data)
"${E[@]}" collect --repos $PWD/services/monitor/data/repos
"${E[@]}" list
"${E[@]}" review approve <id> --reviewer <이름>
"${E[@]}" export --out $PWD/services/erp-updates/data/public/erp_calendar_public.json
```

- 새 버전은 `pending`이라 승인하기 전에는 피드에서 빠진다.
- 캘린더는 요청마다 피드 파일을 읽으므로 재시작할 필요가 없다.
