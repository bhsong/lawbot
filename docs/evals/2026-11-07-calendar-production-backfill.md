# 운영 캘린더 11월 6일 기준 자료 이관 (2026-11-07)

운영 태그 `v5.0.0`의 캘린더 DB에 개발에서 검증한 시행일과 입법예고를 추가했다. 예고 시작일은 2026-10-01부터 2026-11-06까지이며, 기준일 이후로 예정된 시행일과 예고 종료일도 원래 날짜로 표시한다. [작업 계획](../archives/calendar-production-backfill.md)

- 개발 `calendar-v5-verified.db`를 SQLite 사본으로 만들어 v6에서 v7로 올렸다. 운영 수집 원천에서 기존 검증 기준 이후 2026-11-06까지 변경된 법령 파일 49개를 대조했다. v5 대상 법령 폴더의 변경은 0건이었다. 기존 시행 일정 60건, 저장 원문과 공개 보류 5건을 보존했다.
- 열린국회정보 진행·종료 목록 22페이지와 상세 후보 20건을 확인했다. 기존 예고 112건에 11월 5일 시작 1건, 11월 6일 시작 2건을 추가했다. 새 예고 본문 3건과 공식 대비표 8쪽을 검증했다. 총 예고 115건, 시작·종료 일정 230건, 대비표 547쪽이다.
- 운영 DB 사본에 단일 트랜잭션으로 추가하고 같은 입력의 재실행이 무변경인지 확인했다. 운영 기존 수집 시각과 가져오기 이력을 보존했다. SQLite `quick_check`·`foreign_key_check`가 통과했다. 운영 DB 적용 전 백업은 운영 `services/law-calendar/data/calendar.db.pre-20261106-backfill.backup`에 보관했다.
- 운영 DB를 쓰는 독립 API·Chromium에서 10월 예고 일정 158건·시행 3건, 11월 예고 일정 72건·시행 7건을 확인했다. 11월 6일 예고의 본문·대비표 PNG와 10월 8일 시행 조문의 저장 신·구 원문을 열었다.
- 웹앱·모델 서버 재시작과 실제 추론 호출은 없었다. 개발 DB 원본을 보존했으며, 이관은 현재 운영 캘린더 DB의 자료를 채우는 작업이다.
