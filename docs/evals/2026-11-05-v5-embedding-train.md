# v5 임베딩 재학습 (Colab, val 선택 · test 1회, 2026-11-05)

**결론: v5 임베딩(2에폭)은 val 전체 R@10 0.950 → 0.981, MRR@10 0.800 → 0.876으로 v4보다 높다. 세금·보험은 R@10 0.99대, 2,304토큰 초과 긴 조문 R@10 0.832 → 0.972. 다만 노동 법률은 R@10 0.956 → 0.959로 같고 R@1 0.731 → 0.696, MRR@10 0.813 → 0.791로 v4보다 낮다.** 리랭커는 임베딩 상위 10개를 받으므로 노동 법률의 리랭킹 R@3이 유지되는지는 4단계 A를 새 모델로 다시 재서 확인한다. 이 기록은 Colab의 임베딩 단독 지표이며 웹앱·모델 서버를 거치지 않았다.

- 계획: [archives/v5-tax-scope.md](../archives/v5-tax-scope.md) 4단계 (사용자 결정 2026-11-04: 응답을 느리게 하는 설정보다 임베딩 재학습 먼저)
- 노트북: `lawbot_v5_emb.ipynb` (레포 밖, sha256 `70b73f3c56924139…`), 입력·출력 Drive `MyDrive/labor_law/v5/`
- 결과 파일: `results/v5/emb_v5_val.csv`, `emb_v5_test.csv`, `emb_v5_train.json`
- 모델: `models/v5/emb_v5_fp16` (Drive `emb_final_v5_fp16`, Git 제외). 아직 모델 서버에 올리지 않았다

## 학습 구성

| 항목 | 값 |
|---|---|
| 기반 모델 | `Qwen/Qwen3-Embedding-0.6B` (v4와 같음) |
| 학습 | Hard negative(confusable 8,825 · 검색 오답 5,588) + CachedMultipleNegativesRankingLoss, 3에폭 · lr 2e-5 · batch 8 · mini batch 2 · bf16 · seed 42 (v4와 같은 설정) |
| max_seq | 법률 4,352 · 하위법령 5,120 (최장 문서를 256 단위로 올림, 웹앱 `lawbot-max-seq`와 같은 값), 학습은 5,120 |
| 에폭 선택 | val 전체 MRR@10 → 2에폭 (`checkpoint-3604`) |
| 학습 시간 | A100-SXM4-40GB, 246.0분, CUDA 최대 27.5 GiB |
| 조문 | `law_articles_v5_decree.csv` sha256 `a379d1193dcf…` (삭제 제외, 법률 705 · 하위법령 792 두 인덱스, 문서 문자열은 `lawbot.retriever.doc_text`와 같음) |
| 질문 | 노동 법률 A_lsa·B_newlaw (`qa_full_v4`·`split_v4`) + 노동 하위법령 (`qa_decree_v4`·`split_decree_v4`) + 세금·보험 (`qa_tax_v5.csv` `9910fa1d22aa…`, `split_tax_v5.csv` `4764796301d5…`) |
| 분할 | train 14,413 · val 3,606 · test 7,375 (같은 문장이 다른 분할에 없음 확인) |
| 지표 | 정답이 있는 인덱스(법률 또는 하위법령) 안에서 정답 순위. 질문은 query 프롬프트, 법률 max_seq |
