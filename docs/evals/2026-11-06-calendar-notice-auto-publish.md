# 국회 입법예고 자동 공개 검증

- 개발 DB에 있던 근로기준법안(2221981), 근로자퇴직급여 보장법안(2221787), 지방세법안(2221926)의 수집 이벤트를 임시 Monitor 상태와 빈 캘린더 DB에서 다시 처리했다. 기존 정기 sync 경로가 국회 원문과 기간을 대조해 3건을 자동 공개했고, 시작·종료 일정 6건과 주요내용·대비표 113쪽을 반환했다. `assembly-list --notice-sample 3`의 의안과 검토 이력이 일치했다. 재실행은 보강 0건이었고, 임시 경로에 PDF·PNG 파일이 생기지 않았다.
- 테스트에서 예고기간 불일치 후 다음 실행 성공, PDF 실패 후 본문 먼저 공개 및 다음 실행에 이미지 보강, 수동 반려·철회 후 정정본 비공개 유지, 한 배치가 불일치 건에 고정되지 않는 흐름을 확인했다. Chromium 대역 E2E는 자동 공개된 예고와 수동 승인한 의안이 날짜별로 분리되고 상세에서 대비표 이미지가 열리는 것을 확인했다.
- 개발 DB 사본을 검증한 후 `calendar-v5-verified.db`에 SQLite v6 마이그레이션을 적용했다. 기존 예고 112건의 본문·이미지 539쪽, 일정 224건, 시행 상세 60건, 보류 5건, 예고 검토 이력이 이전 DB와 일치했다. `quick_check`와 `foreign_key_check`를 통과했다. 개발 DB에는 자동 처리할 신규 예고나 PDF 재시도 대상이 없었다.
