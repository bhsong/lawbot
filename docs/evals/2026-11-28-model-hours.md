## 질문 경로

- 단위 검사 질문: `주 40시간 일하면 주휴수당은 얼마인가요?`
- 21:30, 설정 `06:00-21:30`에서 표시한 안내: `답변 서비스 운영 시간은 06:00–21:30입니다. 운영 시간에 다시 질문해 주세요.`
- 절차 확인: 모델 호출 0건, 요청 로그 `error_type=off_hours`, 조문 인용·품질 점수 해당 없음. 운영 시간 안이나 미설정이면 접속 실패에 기존 `model_server` 안내를 사용한다.
- 대역 E2E: 로그인 후 시간 밖에 같은 질문을 보내 운영 시간 안내가 표시되고 피드백 버튼이 없어지는 것을 확인했다. 임베딩·리랭크 및 생성 대역의 요청 기록은 질문 전후 동일했다.
