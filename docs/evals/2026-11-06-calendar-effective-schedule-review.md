# PR #75 법령 캘린더 리뷰 반영 검증

- 기존 PR head `a72def6`의 세 지적을 회귀 테스트에서 재현했다. 이전 개정의 근거를 조각별로 확인하고, 인용한 상위 범위의 교체가 입증된 경우 그 범위에 속하는 삭제를 함께 처리한다. 별표·별지의 상대 참조는 본칙과 분리한다. 후속 부칙이 효력 시작일을 정하면 기본 시행일 적용을 보류하고, 종료일만 적힌 경우 기존 시행일 판정을 유지한다.
- `calendar-v5-verified.db` 사본에 `calendar-v5-preview.db`의 저장 원천 개정 20건을 재입력했다. 첫 실행은 갱신 20건·실패 0건, 재실행은 무변경 20건이었다. 개발 DB 두 원본의 전후 SHA-256이 일치했다.
- 보류 5건의 ID·범위·사유와 공개 60건의 ID·날짜·Before/After가 리뷰 반영 전과 전부 일치했다. API와 Chromium으로 8개 날짜의 공개 상세 60건과 보류 목록 5건을 다시 대조했다. 소득세법 시행령 제207조제11항의 기존 상세에는 제1호·제2호 삭제가 함께 표시된다.
- `PYTHONPATH="$PWD/services/law-calendar/src" .venv/bin/python -m pytest -q`로 단위·계약·통합·대역 E2E를 포함한 기본 테스트 893개 통과, 기본 제외 13개.
- 두 프런트엔드 타입 검사·빌드 및 Vitest 37개, Ruff, 루트와 캘린더 Pyright, API 스키마, Python 문법, 두 uv 잠금 파일 검사 통과.
- 실제 모델 E2E·모델 스모크·품질 평가 실행 안 함.
