# 조문 연결 그래프로 리랭크 후보 넓히기: 임시 평가

작성 2026-11-20 KST. 근거: [정의 조문 연결 검증](../evals/2026-11-19-definition-links.md) · [v6 검색 진단](../evals/2026-11-19-reasoning-format-definitions.md#v6-검색-진단)

## 목표

임베딩이 놓치는 보조 조문(정의·기본 원칙·절차 조문)을 조문 원문의 참조 관계로 리랭크 후보에 넣고, 리랭커가 고르게 했을 때 검색과 답변이 좋아지는지 확인한다. 레포 코드는 바꾸지 않고 레포 밖 임시 실행기로 평가한다. 효과가 성공 기준을 넘으면 별도 계획서로 구현(omp)하고, 넘지 못하면 임시 파일을 지우고 결과만 기록한다.

## 그래프 (조문 원문에서 나온 하나의 규칙)

- 법률 조문 본문의 `제N조(의M)` 언급은 같은 법, `「법령」 제N조(의M)` 언급은 다른 법 조문으로 잇는다. 자기 자신, `부칙` 조문, 코퍼스에 없는 대상은 잇지 않는다.
- v5 법률 1,534조문 기준 같은 법 언급 3,582건, 다른 법 언급 390건(코퍼스 밖 대상 1,187건 제외).
- 정의 항목 연결(v6.4.0)은 그대로 두고 비교에 함께 켠다.

## 후보 확장

임베딩 상위 10개(현재 후보)를 출발점으로 그래프 1단계 이웃을 모아, 이미 후보에 있는 조문을 빼고 질문과의 임베딩 유사도 순으로 최대 M개를 후보에 더한다. 리랭커는 후보 전체를 점수 매기고 상위 3개를 모델에 준다.

비교 설정(val로만 선택): 출발점(임베딩 상위 3 / 10), 방향(참조하는 쪽만 / 양방향), 추가 수 M(0·3·5·10). 리랭커는 조문별 점수라 문항마다 "기본 10 + 이웃 최대 10"을 한 번 점수 매기고 설정별 결과는 오프라인으로 계산한다.

## 실행

| 단계 | 대상 | 모델 호출 | 예상 시간 |
| --- | --- | --- | --- |
| 1. 검색 | 추론 val 32문항 + 일반 val 층화 표본 600문항(근로기준법·신법·세금 비율 유지, 고정 시드) | 질문 임베딩 묶음 호출, 리랭크 632회(문항당 후보 최대 20개), 생성 0 | 약 55분 |
| 2. 생성 비교 | 1에서 상위 3개가 바뀐 문항(추론 val 전체 + 일반 val 최대 40문항), 확장 켬·끔 | 생성 최대 약 150건 | 1 결과를 보고 요청 수와 함께 보고 후 실행 |

개발 설정 예시(v5, 리랭커·하위법령·정의 연결 켬), 온도 0, 출력 최대 1,024토큰, 응답 대기 300초, 동시 1, 재시도 없음. 06:20–06:50에는 실행하지 않는다. test 셋은 쓰지 않는다.

## 성공 기준 (실행 전에 정함)

1. 추론 val: 법령 근거 30문항의 기준 조문 전부 제공이 현재 24(정의 연결 포함)에서 **+2 이상**.
2. 일반 val 표본: 리랭킹 R@3이 현재 설정보다 **떨어지지 않음**(표본 600문항 중 정답 이탈 3문항 이하이고 회수가 이탈보다 많음).
3. 지연: 리랭크 시간 증가가 질문당 평균 **1.0초 이하**(후보 수에 비례해 측정).
4. 생성 비교: 바뀐 문항에서 **하락 0**, 추론 val 점수 증가.

네 가지를 모두 만족하는 설정이 있으면 구현을 제안하고, 없으면 임시 파일을 지우고 결과를 `docs/evals`에 남긴다.
