## F032 인용과 정확 일치 캐시

합성 테스트에서 조문·호 뒤 가운뎃점을 법령명 경계로 처리하고, 띄어쓰기가 있는 비등록 법령명의 앞부분을 보존한다. 등록 약칭·하위법령·인용부호·생략 조문 목록의 정상 동작을 확인한다. 실제 운영 답변은 회귀 테스트에 사용하지 않는다.

`768ed44`에서 합성 문장 `가상노동법 제3조제1호·한국철도공사법 제9조`는 `호·한국철도공사법`, `가상노동법 제3조, 농수산물 유통 및 가격안정에 관한 법률 제40조`는 `법률`을 반환했다. 후속 구현의 기대값은 각각 완전한 법령명이다.

라이브·캐시의 표시가 달라지는 범위를 합성 데이터에서 재현한다. 표시가 바뀌면 `DISPLAY_VERSION`과 렌더 스냅샷을 함께 갱신하고, 임시 캐시 DB에서 기존 승인 항목의 재검토 전환과 재승인을 검증한다. 리뷰는 운영 캐시 표본 120개 중 파싱 결과 8개, 그중 승인 5개가 달라졌다고 보고했다. 운영 승인 상태에 대한 적용 결정은 사용자에게 받는다. [표시 변경 계약](../operations.md#p07-정확-일치-캐시)

## F021 수집 이벤트 ID

반복 발생과 재실행을 구분하는 규칙을 정하고, 기존 ID를 읽는 캘린더·ERP와 호환되는지 확인한다. 수집기 README의 이벤트 ID 계약과 이력 재작성·replay·`bootstrap --force` 설명을 같은 변경에서 갱신한다. 일반 수집, 같은 원문 복귀, 반복 삭제, replay, 이력 재작성 대조를 합성 원천으로 검증한다. 캘린더 실제 호환성 확인은 승인받은 운영 캘린더 DB 사본을 레포 밖에서 사용하며 기존 등록·미처리 항목·중복 여부를 대조한다. [현재 계약](../../services/monitor/README.md)

## F018–F020 모델 서버

모델 서버만 대상으로 본문 누적 제한, 임베딩·리랭크 대기열, 연결 종료 취소를 검증한다. 정상 배치와 생성 진행, 큐 회수, GPU 단일 스레드 계약을 합성 요청과 대역 모델로 확인한다. 상한과 시작 제한은 정상 운용 시간을 대조해 고르고, 배포 판단에는 모델 서버 재시작·재로딩 영향을 명시한다.

## F024 Git 시간 제한

일상 fetch, 첫 부분 클론, 누락 blob을 읽는 경로의 소요를 분리해 확인한다. 고정 120초 대신 경로별 제한 또는 운영 설정을 검토한다. 시간 초과 뒤 기존 커서·파일을 보존하고 다음 실행에서 복구되는 것을 임시 원천과 함께 검증한다.
