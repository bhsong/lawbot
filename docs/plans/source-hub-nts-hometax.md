# 국세청·홈택스 공식 자료 연동

공통 수집기를 재사용하는 별도 PR이다. PR #132가 병합되기 전에는 그 브랜치를 기준으로 리뷰한다. [통합 계획](source-hub-erp-v1.1.md)

1. 국세청 공식 오픈 API 안내, 저작권 정책, `robots.txt`, 공개 메뉴를 대조한다. 해당 게시물을 제공하는 API가 확인되지 않으면 공지·고시·연말정산 참고·원천세 참고·프로그램 게시판의 제목·게시일·공식 링크를 내부에 저장한다.
2. TAX-02는 국세청 연말정산 종합 안내에서 안내책자 제목과 공식 안내 링크만 확인한다. 게시일이 표시되지 않으면 비워 둔다. 다운로드 링크·원본 파일·본문·저작물 재배포는 별도 확인 대상으로 남긴다.
3. 홈택스는 공개 안내와 이용 조건을 확인한다. 허가된 자동 경로가 확인되지 않으면 기본 OFF와 `manual_review`로 유지한다. 국세청이 직접 게시한 프로그램 목록과 개발자 설명회 표지를 별도 출처로 수집한다. 운영자가 실제 홈택스 게시 사실을 확인하면 식별자·제목·확인된 게시일만 등록하고, 홈택스 공식 홈에서 제목으로 찾을 수 있게 한다.
4. 기존 SQLite 호환, ON/OFF 무요청, 주소 일치, 수정·중복, 날짜 미확인, 상세·첨부 무요청을 대역과 실측으로 검증한다. 국세청과 홈택스 코드만 별도 PR에 포함한다.
