# 고용노동부 공식 RSS 수집

[통합 수집기 계획](source-hub-erp-v1.1.md)의 PR-B를 고용노동부 공식 RSS 세 채널로 시작한다. 개발 기준은 `main`의 `b14d666`이다.

1. 고용노동부의 RSS 안내, `robots.txt`, 저작권 정책과 세 채널의 실응답을 대조한다. 확인 근거와 실측을 기록한다. 자료는 등록한 공식 HTTPS RSS에서만 읽고 게시물 제목·공식 링크·게시일과 RSS 식별자만 내부 DB에 저장한다.
2. 등록부를 실행당 한 번 읽고 소스·기관·그룹이 켜진 상태에서 검증된 세 경로만 수동 CLI로 수집한다. 요청 전에 `robots.txt`를 확인하고 제한·정책 확인 실패·리디렉션 응답에서 중단한다. 출력과 수집 이력에서 비활성·오류·신규 0건을 구분한다.
3. 게시글 ID로 중복을 제거하고 초기 기준선·신규·수정판을 SQLite에 기록한다. 소스별 실행 간격을 지키고 동시 실행을 제한한다. 수집된 메타데이터와 실행 기록을 CLI로 확인한다. 기존 등록부 DB와 게시물 DB는 분리한다.
4. 대역에서 OFF 요청 0건, 켜기·끄기·다시 켜기, 날짜·링크·중복·실패를 검증한다. 허용 조건을 확인한 공식 피드는 임시 DB에서만 실측한다. 기본 검증 전체를 통과한 뒤 PR을 올린다.

이번 PR의 실행 경로는 Source Hub의 고용노동부 RSS 수동 수집이다. 게시판 대조, 다른 기관 어댑터와 최신 소식 공개는 PR-B 후속 작업이다. 기존 `law-monitor daily`, 캘린더 sync, 조문 자동 갱신, 모델 서버, 운영 서비스는 변경 범위 밖이다.
