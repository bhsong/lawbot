# 기관 소식 공개 검토 관리자 화면

기준 `68af3f9`. [기관 소식 공개 계약](../archives/erp-agency-news.md)

1. 기존 비공개 수집 관리자에 소스별 검토 대기·승인·철회 목록을 추가한다. 현재 수집판과 마지막 이전 승인판의 제목·게시일·공식 링크를 나란히 표시한다.
2. 화면과 CLI는 같은 리비전 감사 기록을 사용한다. 승인과 재승인은 사유 없이 저장하고, 철회에는 사유를 필수로 받는다. 화면에서 선택한 판 또는 결정이 바뀌면 충돌로 알리고 목록을 갱신한다. 인증, 동일 출처 JSON 쓰기 제한, 출처·권리 조건을 적용한다.
3. 관리자가 화면에서 공개 스냅샷을 갱신하고 마지막 갱신 시각과 현재 공개 대상의 일치 여부를 확인한다. 비공개 DB와 공개 파일 경로는 프로세스 시작 옵션으로 고정한다. 파일 교체 전 실패는 기존 파일을 보존한다.
4. 임시 DB로 신규·재승인·철회·갱신 흐름과 권한·경합을 검증하고, 로컬 Chromium 대역과 기본 전체 검증을 통과하면 PR을 올린다. ERP 공개 API, 챗봇 조문 갱신과 운영 설정은 유지한다.
