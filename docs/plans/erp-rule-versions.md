# ERP 현행·예정 적용 기준

2026-11-13 KST. 기준 `12a1347`. [통합 구현 계획](source-hub-erp-v1.1.md)

1. 첫 PR에서 기존 ERP 자료·승인·첨부 이력을 유지한다. 업무 항목은 등록된 원천 키로 명시적으로 연결하고, 적용 범위별로 검토 판과 전환 근거를 기록한다. 별도 내보내기와 읽기 전용 v2 API를 추가한다.
2. 공적 근거와 승인 원천 리비전, 시작일, 범위, 확인된 내용이 갖춰진 판만 확정한다. KST 기준일과 업무 적용 기준일·월·연도로 분리해 현행 및 후속 판을 판정한다. 재확인 필요, 연기·철회, 검토 중을 구별하고 과거 판정 이력을 보존한다. 검증되지 않은 수치 비교는 원문 확인으로 연결한다.
3. 두 번째 PR에서 기존 6종의 원문·수집 이력과 법령 일정·기관 드로어를 보존한다. 동일 업무 항목의 현행과 가장 이른 확정 변경을 한 카드에 배치하고, 복수 변경과 별도 적용 범위는 펼쳐 볼 수 있게 한다. 기존 자료에 확인된 현행판이 없으면 이를 표시한다.
4. 합성 자료로 기존 v1 호환, KST 경계와 적용 대상, 부분 시행, 미검증·철회·연기, 과거 조회를 검증한다. React·Chromium으로 카드와 원문 링크를 검증한다. 운영 DB·스케줄과 챗봇 경로는 기존 구성을 사용한다.
