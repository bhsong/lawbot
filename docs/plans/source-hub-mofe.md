# 재정경제부 공식 수집 연동

고용노동부 게시판 대조 PR #132에 추가한다. 재정경제부의 공식 RSS와 확인된 공개 목록에서 제목·게시일·공식 링크만 내부 자료 DB로 가져온다. 공공누리 확인이 필요한 원문과 첨부는 별도 검토 대상으로 둔다. [통합 계획](source-hub-erp-v1.1.md)

1. 재정경제부 공식 RSS 안내, 저작권 정책과 `robots.txt`를 대조한다. 세제 자료를 제공하는 별도 공개 API가 확인되지 않은 경우 보도·설명·정책 RSS 및 공식 게시판을 연결한다.
2. 고용노동부의 실행 간격·ON/OFF·SQLite 이력·부분 실패 처리를 재사용한다. 재정경제부 URL은 호스트, 경로와 게시판 ID가 일치할 때만 요청한다. 게시글 링크는 확인된 HTTPS 형식으로 만들고 상세 요청은 실행하지 않는다.
3. 보도·설명·공지·정책 목록을 해당 RSS와 대조한다. 법령자료실·고시·입법예고는 공식 목록에서 식별한다. 게시일을 확인할 수 없는 자료의 날짜는 비워 둔다. 정적 자료·첨부·별도 이용 확인 대상은 등록부에 남긴다.
4. 대역과 임시 DB 실측을 분리하고 권한 차단·중복·OFF·기존 조문 갱신 회귀를 검증한 뒤 #132를 갱신한다. 국세청·홈택스는 별도 PR에서 진행한다.
