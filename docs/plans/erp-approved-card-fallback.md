# ERP 기존 승인 카드 표시 복구

2026-11-13 KST. 기준 `67c4086` (`v5.8.0`). 운영 ERP v1의 승인 자료 6건과 공식 링크가 유지되어 있다. v2는 동일한 원천 키 6개를 내보냈지만 적용 범위와 검토 링크가 비어 있다. 화면이 원천 키만으로 v1 카드를 대체해 본문을 숨기고 ‘현행 기준 확인 필요’ 카드만 표시한다.

건별로 v2의 적용 범위 또는 검토 링크가 있는 경우 기존 v2 카드를 사용한다. v2가 정상이고 같은 원천에 표시할 판이나 검토 링크가 없으면 기존 승인 자료를 본문·날짜·원문·첨부와 함께 보여 준다. 자료 기준일과 v2의 현행 효력 검증은 각각 표시한다. v2 적용 범위가 있는 카드의 미확인 상태와 v2 응답 실패 시 원문 참고 표시를 보존한다.

운영과 같은 빈 v2 항목, 혼합 v1/v2, 기존 PDF와 본문 표시, 자료 중복 방지를 React 및 캘린더 Chromium 대역에서 검증한다. 공개 계약과 운영 DB에 새 승인 이력을 추가할 필요가 없다.
