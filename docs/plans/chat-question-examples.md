# 챗봇 시작 화면의 예시 질문 변경

1. 첫 카드에는 P07 통과 문항 Q1314의 원문을 사용한다. 임시 v5 코퍼스와 캐시 DB에서 표시본과 근거를 확인하고 활성 상태의 정확 일치 적중을 확인한다. 운영 캐시 등록 및 활성화는 범위 밖이다.
2. 둘째 카드는 기존 해고 예고 질문을 사용한다. 셋째 카드는 실손보험금 차감과 총급여 기준을 함께 적용하는 의료비 세액공제 계산을 묻는다. 기존 기록과 v5 코퍼스, 국가법령정보센터 조문으로 답변 내용을 대조한다.
3. `/api/config`가 v5에서 내보내는 예시 목록을 교체한다. 소득세법이 없는 v4는 기존 노동법 예시를 유지한다. 버튼은 기존 모델과 답변 형식으로 질문 원문을 보낸다. 실제 모델 E2E의 기존 노동법 질문을 고정하고, 가짜 모델로 세 카드의 전송과 첫 카드의 캐시 적중을 확인한다.
4. 기본 테스트, 정적 검사, 두 프런트엔드 검증 결과를 기록한다. 실제 모델 검증은 별도 승인 조건을 따른다.
