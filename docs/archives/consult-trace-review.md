# 상담 전체 추적 저장: PR 2 Astra 리뷰 반영

대상: [승인된 1단계](../archives/consult-trace-clarify.md#1단계-상담-전체-추적-저장-pr-2-2026-11-24-착수-승인). 검색·생성·인용과 모델 요청은 그대로 두고 추적 저장, 전송 분류, 관리자 조회만 수정한다. 0003은 아직 미적용이므로 새 마이그레이션을 추가하지 않는다.

1. 가림: gzip 전체 멤버와 헤더를 검사할 수 없으면 원문을 버린다. JSON 문자열의 해석값에서도 찾고, 변경 없는 바이트는 유지한다. 웹 포트는 호스트 문맥에서만 가린다. SSE 토큰 재조립은 범위 밖이다.
2. 경계: 최종 SSE를 만들 때 결과를 확정하고 ASGI 전송 확인을 별도 기록한다. 모델 호출에는 송신 확인 상태와 해당 호출에서 발생한 오류만 남긴다. SSE 이벤트 단위로 usage를 읽는다. 상담 UUID는 고유, 요청 로그 연결 키는 비고유다.
3. 관리자: 읽기 스냅숏에서 미리 보기 건수를 구하고 세션에 묶는다. 삭제 때 쓰기 잠금에서 재검증한다. 상세 첫 응답에는 메타데이터만, 원문은 선택 항목에 대해 조회한다. 스트림 조각은 순서와 바이트 오프셋을 보존하며 잘라 반환한다.
4. 검증: 회귀 Red → 수정 → 대역 네트워크 연결 본문, transport 경계, 브라우저, 기본 전체 및 CI 정적·화면 검사. 실제 모델·운영·기존 개발 DB에는 접근하지 않는다. 평가 기록 갱신 후 로컬 커밋만 남긴다.
