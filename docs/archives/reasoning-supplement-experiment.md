# 누락 조문을 보강한 v5 답변 비교

- 기존 법률 추론 val에서 기준 조문이 누락된 7문항을 사용한다. 기존 법률 3개와 실제로 첨부된 하위법령 최대 2개를 같은 순서로 둔다. 누락 기준 조문 1~2개를 뒤에 붙이고 기준 답변 원문은 프롬프트에 넣지 않는다.
- 승인된 공유 모델 서버에서 같은 v5 Pro 간결형과 조문 스냅샷으로 답변만 순차 7회 생성한다. 온도 0, 최대 1,024토큰, 대기 상한 300초, 자동 재시도 0회다. 실행 전후 모델 revision, 커밋, 설정과 조문·프롬프트 해시를 대조한다.
- 질문별로 기존·보강 답변의 내용 판정, 조문 인용, 추가 입력량과 보강 후 생성 시간을 기록한다. 보강 조문을 미리 아는 조건의 실험이며 자동 검색으로 보강 조문을 고르는 품질은 후속 검증 범위로 둔다.
