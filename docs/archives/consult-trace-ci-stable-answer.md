# PR #197 상담 추적 대역 시험의 시간 의존 제거

- 재현 근거: macOS CI에서 추적 켜짐·꺼짐의 답변 영역을 비교할 때 검색·리랭킹 시간 차이로 실패했다. 기존 CI 실패를 Red로 삼는다.
- 기존 본문에 테스트 식별자를 붙인다. 켜짐·꺼짐 비교는 본문과 조문 카드에 한정하고 측정 줄은 별도로 확인한다. 스트리밍의 중간 문자열 비교도 본문에 한정한다. 검색·답변·인용 동작은 변경하지 않는다.
- 화면을 다시 빌드하고 기본 테스트 전체와 Ruff·Pyright를 실행한다. 대역 검증을 기록하고 로컬 커밋 하나만 만든다. 실제 모델을 호출하거나 운영 환경을 변경하지 않는다.
