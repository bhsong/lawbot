# PR #75 캘린더 시행일 리뷰 반영

- 변경 조각마다 이전 개정 이력을 확인한다. 인용한 상위 범위에 포함된 삭제는 해당 상위 범위의 교체 근거와 대조한다.
- 별표·별지로 넘어가면 본칙 조문 참조를 끊는다. 뒤쪽 부칙이 효력 시작일을 따로 정하면 기본 시행일로 공개하지 않는다.
- 각 리뷰 사례를 실패하는 테스트로 재현하고 개발 DB 사본의 원천 20건으로 재검증한다. 보류 5건과 공개 60건의 날짜 및 Before/After가 일치하는지 확인하고 기본 검사 통과 후 기존 PR을 갱신한다.

개발 DB 재처리와 브라우저 전수 대조에서 보류·공개·비교 건수가 일치했고 기본 테스트 893개를 통과했다. [검증 기록](../evals/2026-11-06-calendar-effective-schedule-review.md)
