# 법률 추론 val 리뷰 반영과 검색 원인 확인

- PR #81의 평가 중단 경로에서 실패 단계, 원인, 예외 연결과 traceback을 보존한다. 모델 서버 주소와 토큰을 가린 뒤 새 실행 폴더의 진단 파일과 표준 오류에 남긴다.
- 사전 확인 HTTP 오류와 앱 초기화 오류를 가짜 모델 경로로 재현하고 기본 테스트·품질 검사 후 같은 PR에 반영한다.
- 기존 평가에서 최종 근거가 누락된 7문항만 별도 승인 후 검색 재현한다. 기준 조문의 임베딩 전체 순위와 후보 10개 내 리랭킹 순위를 확인하고 기존 상위 3개와 대조한다.
- 기존 데이터셋과 평가 결과를 보존한다. 답변 원문에서 확인할 수 있는 생성 오류를 검색 단계 결과와 구분해 별도 기록한다.
