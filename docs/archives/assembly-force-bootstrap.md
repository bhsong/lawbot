# 국회 수집기 강제 bootstrap 기준점 갱신

- 작성일 2026-11-05 · PR #73 리뷰 후속 구현 완료
- 이미 추적 중인 의안과 예고의 공식 내용이 바뀐 뒤 `bootstrap --only <수집기> --force`를 실행하면 관측 순번을 보존하면서 비교 스냅샷을 현재 내용으로 갱신한다.
- 합성 의안과 예고로 강제 bootstrap 뒤 같은 원천의 정상 수집이 이벤트를 만들지 않는지 먼저 재현한다. 이후 실제 원천 변경에 해당하는 합성 입력이 한 건의 다음 순번 이벤트를 만드는지 확인한다.
- 이전에 이벤트를 발행한 예고는 강제 bootstrap에서도 공식 상세 기간을 대조한다. 동일 종료일에 대해 확인한 시작일은 재사용한다. 아직 발행하지 않은 진행 예고는 기존 첫 정상 수집에서 검토 후보로 발행한다.
- 기본 테스트 전체와 정적 검사를 통과한 뒤 기존 PR을 갱신한다. 이번 회귀는 대역으로 재현하며 운영 반영과 실제 추론은 범위 밖이다.
- 재현 및 최종 검사 결과는 [후속 검증 기록](../evals/2026-11-05-assembly-force-bootstrap.md)에 있다.
