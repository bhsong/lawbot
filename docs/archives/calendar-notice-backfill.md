# 개발 캘린더 입법예고 소급 입력

- 이전 작업에서 검증한 개발 캘린더 DB에 2026-10-01 이후 시작한 제22대 국회 입법예고를 가져온다. 대상은 기존 Monitor 설정의 제목 키워드를 따른다.
- 열린국회정보 진행·종료 목록과 공식 상세의 의안번호·예고기간을 대조한다. 두 날짜가 확인된 게시물은 기존 캘린더 가져오기·검토 경로로 입력해 시작일과 종료일에 표시한다.
- 임시 DB에서 월별·일별 API와 Chromium을 확인하고 동일 입력 재처리 및 기존 법령 일정·보류 보존을 검증한다. 개발 DB의 기존 내용을 백업한 뒤 새 예고를 추가한다. 운영 환경과 수집 스케줄은 작업 범위 밖이다.
