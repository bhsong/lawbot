# 계획 — PR #157 val 벡터 저장과 재로드

- 기준 `ca04f96`. `eval_suggestions`에서 학습 문장 제외 곡선과 선택 규칙을 유지하고, 질의 벡터 저장·재사용을 개발 `results/` 아래에서 제공한다.
- 저장 파일에는 질의 ID, 벡터, 임베딩 모델·revision, 최대 인코딩 길이, 라벨 SHA-256만 기록한다. 재로드는 현행 정보와 ID 집합을 대조해 곡선을 계산하며 임베딩 예산을 쓰지 않는다.
- CLI는 벡터 저장을 마친 뒤 지정 결과 경로에 곡선을 직접 쓴다. 출력과 저장 경로는 새 파일을 요구하고, 실행 오류가 나도 산출물을 보존한다.
- 합성 테스트 Red → Green, 기본 pytest·Ruff·Pyright 통과, 기존 PR 푸시 순으로 검증한다. 승인된 실제 val은 기존 개발 DB로 113회 한 번만 실행하고 두 곡선과 선택 결과를 기록한다.
