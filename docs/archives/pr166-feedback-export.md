# PR #166 피드백 내보내기 회귀 수정

## 목표·범위

학습 원문이 없는 과거 기록 때문에 정상 기록까지 내보내지 못하는 문제를 수정한다. 폐기된 응답 출처 이름이 아니라 내보내기가 읽는 필드의 존재 여부와 null 여부로 제외한다. `reason=null`과 빈 `hits`는 허용한다. 프로필 미지원 제외 방식처럼 출력 전에 제외하고 건수를 알린다.

## 단계·완료 기준

1. 정상 기록과 `system` 누락·`answer_raw=null` 과거 기록을 함께 검수한 CSV 회귀 테스트를 추가하고 KeyError Red를 확인한다.
2. 필수 필드가 없는 기록을 모든 출력·분할·조문 검증 전에 제외한다. 정상 기록의 네 CSV와 제외 건수를 확인한다.
3. 요청한 Ruff 검사·포맷 검사·Pyright·feedback/export pytest를 실행하고 결과를 docs/evals에 기록한다.

커밋·푸시·브랜치 변경, .env 접근, 운영 트리 접근, 실제 모델 호출은 하지 않는다. 다른 대기 계획은 이번 수정과 무관하므로 유지한다.

## 완료

16개 매개변수 회귀 사례를 포함해 feedback/export 83개 통과. Ruff 검사·포맷 검사·Pyright 통과. [검증 기록](../evals/2026-11-18-pr166-feedback-export.md).
