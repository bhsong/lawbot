# 고용노동부 공식 게시판 목록 대조

기준 `main` `788def5`. [통합 수집기 계획](../plans/source-hub-erp-v1.1.md)의 PR-B를 이어 세 RSS 채널을 대응하는 공식 게시판과 대조한다.

1. 공식 안내·정책과 목록 1·2페이지의 실제 요청을 확인한다. 허용된 HTTPS 목록의 제목·게시일·공식 링크만 읽고, 상세·첨부는 내려받지 않는다. 기존 요청 제한과 리디렉션 거부를 유지하고 페이지 쿼리까지 `robots.txt`를 확인한다.
2. 기존 `collect`에 목록 대조를 선택하는 옵션을 추가한다. 대조 실행은 소스·기관·그룹 ON, 수집 간격과 별도의 목록 대조 간격을 적용한다. 1페이지에서 확인한 페이지 링크를 따라 최대 2페이지를 읽는다. 접근 제한·목록 구조 오류는 RSS 성공과 분리해 부분 실패로 기록한다.
3. 기존 자료 DB를 열 수 있게 유지한다. `bbs_seq`로 RSS와 목록을 결합하고 첫 대조에서 발견된 목록 전용 글은 기준선으로 보존한다. 이후 겹치는 구간에서 누락과 수정은 한 번만 기록하고, 목록에서 빠졌다는 이유로 삭제하지 않는다. 게시판에서 확인한 제목·날짜와 RSS의 식별자를 보존한다.
4. 합성 검증으로 누락, 수정, 중복, 첫 대조 기준선, 실패, OFF 요청 0건과 구버전 DB 호환을 확인한다. 실측은 개발 임시 DB에서 수행하고 결과를 `docs/evals/`에 기록한다. 기본 검증을 통과하면 PR을 올린다.

기존 법령 수집·캘린더·챗봇 조문 갱신과 운영 스케줄에는 변경을 적용하지 않는다.
