# 국회 입법예고 자동 공개와 본문 수집

- 기존 캘린더 정기 sync에서 국회 입법예고의 의안번호와 시작·종료일을 공식 상세와 대조한다. 현재 snapshot이 검토 대기이면 일치할 때만 자동 공개하고 검토 이력에 근거를 남긴다. 의안과 법령 시행 일정은 기존 절차를 유지한다.
- 주요내용과 대비표는 같은 실행에서 SQLite에 저장한다. 상세 대조에 실패하면 다음 실행에서 다시 확인한다. PDF만 실패하면 확인된 본문을 공개하고 PDF 재시도 상태를 DB에 기록한다. 정정이 들어오면 새 snapshot을 검증하고, 반려·철회한 예고는 자동으로 재공개하지 않는다.
- 기존에 공개한 예고와 원문은 유지한다. 자동 공개 이력과 남은 예외를 점검 출력과 관리 명령에서 확인할 수 있게 한다. 실제 운영 등록이나 생성기 변경 없이 회귀 테스트와 개발 DB 검증을 거쳐 PR #76을 갱신한다.

[검증 기록](../evals/2026-11-06-calendar-notice-auto-publish.md)에 실제 국회 예고 3건의 자동 공개 결과, 기존 개발 DB 보존 확인 및 기본 테스트 결과를 정리했다.
