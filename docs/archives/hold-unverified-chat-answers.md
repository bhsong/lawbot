# 검증을 통과하지 못한 챗봇 답변의 표시

2026-11-14 KST. 기준 `main` `9be6850`.

일반 답변은 지금 생성 중인 본문을 그대로 전송하고, 생성 후 인용 판정이나 계산 카드와의 비교에서 문제가 확인돼도 그 본문을 최종 표시한다. 인용 판정과 계산 결과 카드를 재사용해 화면의 최종 본문을 결정한다.

1. 일반 답변의 본문은 생성 중에 초안으로 표시한다. 완료 시 인용 누락, 입력 근거에 없는 인용, 출력 토큰 상한으로 잘림이 확인되면 본문을 확인 필요 안내로 교체하고 검색 조문을 참고용으로 표시한다. 기존의 정상적인 근거 부족 거절과 확인된 인용은 그대로 표시한다. 인용 확인의 범위는 모델에 제공한 조문과 대조하는 데까지다.
2. 계산이 완료되면 계산 카드의 수치와 조건을 보여 준다. 모델 설명은 검사 전까지 전송을 보류한다. 모델 결론의 숫자가 카드와 다르거나 확인되지 않으면 카드와 안내를 표시한다. 계산기의 확인된 근거는 검색 결과와 별도로 전달되므로 계산된 답변에는 기존 계산 비교를 적용한다. 계산 입력이 부족하다는 기존 안내를 표시한다.
3. 최종 판정 사유를 요청 로그에 남긴다. 보류된 본문은 복사할 수 없고 피드백 승격 경로에도 들어가지 않게 한다. 정확 일치 캐시 경로와 모델 호출 경로는 기존 방식을 따른다.

단위·계약·통합·대역 E2E에서 정상 인용, 거절, 인용 누락·검색 근거 밖 인용, 잘림, 계산 일치·불일치·숫자 누락, 초안 교체와 카드 유지 여부를 확인한다. 기본 테스트 전체와 린트·타입·빌드를 실행한다. 실제 모델 시험은 별도 승인 대상이다.
