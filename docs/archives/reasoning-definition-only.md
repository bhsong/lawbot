# 1위 법률 조문의 타법 정의 보강 검증

- 저장된 추론 val 30문항과 일반 법률 val 1,247문항에서 기존 오프라인 규칙을 재현한다. 1위 법률 조문이 쓰는 타법 정의를 찾으면 기존 조문을 유지한 채 1개만 바로 뒤에 삽입한다. 후보 선택에 기준 답변을 쓰지 않는다.
- 규칙이 발동한 ERR002·ERR007과 Q2761·Q2901을 비교한다. ERR002·ERR007은 기존 평가의 답변을 대조군으로 쓰고 보강 답변만 새로 생성한다. Q2761·Q2901은 저장된 기존 근거와 보강한 근거에서 각각 한 번 생성한다.
- 승인 후 기존 v5 간결형으로 총 6회 순차 생성한다. 온도 0, 출력 상한 1,024토큰, 대기 상한 300초, 재시도 0회다. 임베딩과 리랭킹은 호출하지 않는다. 질문·조문·모델·시스템 프롬프트를 실행 전후 대조하고 내용 판정, 인용, 시간을 로컬에 기록한다.
