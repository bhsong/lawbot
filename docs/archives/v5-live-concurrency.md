# PR #79 실제 모델 E2E 구성 기록 보완

2026-11-07. 실제 모델 E2E에서 동시 생성 상한이 빠졌다는 리뷰를 반영한다. 개발 환경 변수는 웹앱이 사용하는 값이므로 공유 모델 서버의 설정을 증명하지 못한다. [리뷰](https://github.com/bhsong/lawbot/pull/79#discussion_r4499148717)

1. 인증된 `/health?runtime=1`에 현재 스케줄러의 동시 생성 상한을 추가한다. 일반 `/health` 응답의 기존 형식은 유지한다.
2. 실제 모델 E2E 시작 전 서버에서 이 값을 확인한다. 응답에 유효한 값이 없으면 질문을 보내기 전에 실패 처리한다. 시작·종료 스냅샷에 넣고 값이 다르거나 종료 응답에서 사라지면 실행을 무효로 기록한다.
3. 대역 서버의 상태 응답, 인증, 구버전 서버의 사전 중단, 한도 변경 감지를 테스트한다. 전체 기본 테스트와 정적 검사를 통과한 뒤 기존 PR을 갱신한다.

서버 코드 수정은 메타데이터 제공에 한정한다. 이번 검증에는 대역을 사용하며, 해당 엔드포인트의 운영 반영은 별도 운영 절차에서 다룬다.
