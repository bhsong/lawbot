# 운영 캘린더 10월 이후 자료 이관

2026-11-07. 시연에 필요한 시행일과 입법예고를 2026-11-06 기준으로 보완하고 운영 캘린더에 추가한다. 자료 기준일 이후라도 이전에 공포되거나 예고가 시작된 항목의 시행일·종료일은 원래 날짜를 유지한다.

1. 검증된 개발 캘린더 DB를 SQLite 사본으로 만들고 v7로 올린다. 11월 6일까지 들어온 개정을 운영 수집 원천의 최신 이력과 대조한다. 국회 진행·종료 공식 목록과 상세 원문으로 예고 누락과 기간 정정을 확인하고 기존 검증 경로로 추가한다.
2. 운영 DB 사본에 도메인 자료와 검토·첨부 이력을 추가한다. 기존 운영 수집 상태를 보존하고, 외래 키와 무결성, 월별·일별 조회와 상세를 확인한다.
3. 운영 DB를 SQLite backup으로 보관한 뒤 검증한 추가 작업을 단일 트랜잭션으로 적용한다. 커밋 전 불일치는 롤백하고, 운영 캘린더 API·Chromium을 확인한다.
