# 근거를 연결하는 프롬프트 비교

- ERR001·ERR012에서 직전의 인접 배치 조문을 같은 순서로 제공한다. v5 간결형 시스템 프롬프트에 조문별 근거 연결과 예외의 조건·효과를 짝지으라는 한 줄만 더한다.
- 기존 0점·0.5점에서 한 문항이라도 내용 점수가 오르면 같은 실행 구성으로 나머지 28문항을 순차 생성한다. 30문항 비교에는 먼저 생성한 두 답변을 포함한다.
- 기준선에 저장된 검색 결과를 쓴다. 기준 조문이 빠진 7문항에만 누락 조문을 관련 기본 조문 뒤에 붙인다. 기준 답변은 모델 입력에 넣지 않는다. 정답 조문을 미리 아는 조건으로 비교한다.
- 모델 서버 호출은 우선 생성 2회, 조건 충족 시 추가 생성 28회다. 임베딩·리랭킹 0회, 순차 실행, 온도 0, 최대 출력 1,024토큰, 대기 상한 300초, 재시도 0회다. 앱과 운영 설정을 바꾸지 않고 결과를 개발 트리에 기록한다.
