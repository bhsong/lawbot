# 캘린더 입법예고 검토 대기 목록

- 기존 보류 목록에서 법령 시행일 보류와 국회 입법예고 검토 대기를 각각 조회할 수 있게 한다. 기존 보류 API의 기본 응답과 날짜별 일정 집계를 유지한다.
- 현재 검토 대기인 예고의 공개 국회 메타데이터만 표시한다. 의안번호, 검토 대기 사유, 수집 시각과 공식 원문 링크를 제공한다. 승인·반려·철회한 예고 및 별도 법률안은 대기 목록에서 제외한다.
- API와 데스크톱·모바일 브라우저 테스트로 범위, 페이지, 표시와 기존 보류 회귀를 확인한다. 개발 DB를 읽기 전용으로 확인하고 PR #76에 이어서 반영한다.

[검증 기록](../evals/2026-11-06-calendar-notice-pending-list.md)에 개발 DB와 검토 대기가 있는 시험 DB의 결과를 정리했다.
