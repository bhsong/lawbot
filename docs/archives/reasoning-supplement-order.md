# 보강 조문의 위치 비교

- 누락 조문 보강 실험에서 계속 불일치한 ERR001·ERR012를 사용한다. 같은 조문을 그대로 제공하며, 뒤에 붙였던 보강 조문을 관련 기본 조문 바로 뒤로 옮긴다. 기존 조문들의 상대 순서와 보강 조문들의 상대 순서, 모델, 프롬프트, 질문은 유지한다.
- 승인된 공유 모델 서버에서 문항당 생성 1회, 총 2회를 순차 실행한다. 임베딩·리랭킹 0회, 온도 0, 출력 최대 1,024토큰, 응답 대기 상한 300초, 재시도 0회다. 실행 전후 구성을 이전 실험과 대조한다.
- 원문, 조문 순서, 판정과 인용을 기록하고 기존의 끝 배치와 비교한다. 새 실험 기록은 개발 트리에 둔다.
