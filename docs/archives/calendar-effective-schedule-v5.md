# 법령 캘린더 v5 시행일 판정

- 기준은 PR #74가 병합된 main이다. 캘린더의 부칙 해석·원문 분리·가져오기와 검증에 한정한다. 기존 계획 문서는 미완료 항목이 함께 있어 유지한다.
- 적용례·경과조치와 시행일 조항을 구분한다. 편집 표기를 보존하면서 문장형 단서와 번호 목록을 같은 시행일 규칙으로 읽는다. 조·항·호·목의 상대 참조, 범위, 본문과 별표·서식의 구분을 공통 규칙으로 처리한다. 조건부 시행이나 불확실한 범위는 근거가 확인되는 변경과 분리한다.
- 저장된 신·구 원문에서 실제 변경만 찾아 해당 시행일에 연결한다. 같은 원천 재처리 시 공개·보류를 중복 생성하지 않고 수동 검토를 보존한다. 타법개정 표본 2조문은 기존 보류 판단을 유지한다.
- 단위 및 API·브라우저 회귀를 먼저 작성하고, 개발 v5 DB의 사본으로 전수 재입력한다. 보류 목록과 사유, 공개 일정의 날짜, 모든 공개 항목의 Before/After 원문 및 기존 공개 일정의 회귀를 확인한다. 기본 검사 전체 후 main 대상 PR을 연다.

## 결과

개발 DB 사본에서 일정 60건의 날짜와 저장 원문, 보류 5건과 사유를 API·Chromium으로 확인했다. 기본 pytest 885개와 정적·프런트엔드 검사 결과는 [검증 기록](../evals/2026-11-06-calendar-effective-schedule-v5.md)에 남겼다.
