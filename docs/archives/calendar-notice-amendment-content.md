# 입법예고 상세의 변경 내용과 공식 대비표

- 국회 공식 상세에서 의안번호와 저장된 예고 기간을 대조한 뒤 주요내용을 저장한다. 제안이유와 한 문단에 들어 있으면 함께 보존한다. 원문 HTML은 화면에 주입하지 않는다.
- 공식 법률안 PDF에서 현행과 개정안이 나란히 있는 신·구조문대비표를 확인해 상세창에서 펼칠 수 있게 한다. 원문 링크와 페이지 번호를 유지하고, 구분 근거가 부족한 PDF는 공식 파일 링크를 제공한다.
- 캘린더의 공개 승인과 스냅샷 경계를 유지한다. 기존 예고를 위한 개발 DB 보강 명령을 두고, 날짜 집계·보류·법령 개정 비교를 회귀 검증한다. 공개 API는 저장된 내용만 읽는다.
- 파서·검증·마이그레이션·공개 상세의 실패 테스트부터 작성한다. 개발 DB 사본의 112건으로 원천 수록률과 데스크톱·모바일 상세를 확인하고, 검증 후 개발 DB에 입력한다. 전체 기본 검사 후 main 대상 PR을 연다.

[검증 기록](../evals/2026-11-06-calendar-notice-amendment-content.md)에 개발 DB 결과와 테스트를 정리했다. 112건 모두 주요내용과 공식 대비표를 표시하며, 예고 일정 224건과 기존 시행 상세 60건·보류 5건을 대조했다.
