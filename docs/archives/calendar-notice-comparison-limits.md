# 입법예고 대비표 처리 한도 안내

- PDF 페이지 수와 PNG 크기 한도 초과를 대비표가 없는 정상 응답과 구분한다. 한도 사유를 DB와 수집 출력에 남기고 기존 이미지를 보존한다.
- 주요내용과 공식 PDF 링크를 표시하고, 기존 이미지가 있으면 이전에 저장한 대비표임을 표시한다. 한도 초과는 정기 재시도에서 제외하고 새 스냅샷 또는 수동 재수집 시 다시 확인한다.
- 두 한도 분기, 기존 이미지 보존, 일시 오류 재시도, v6 읽기와 v7 마이그레이션, 브라우저 안내를 검증한 뒤 PR #77을 갱신한다.

[검증 기록](../evals/2026-11-06-calendar-notice-comparison-limits.md)에 한도 분기와 개발 DB 사본의 마이그레이션 결과를 정리했다.
