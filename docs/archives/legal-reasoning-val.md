# 법률 추론 회귀 검증 30문항

- 사용자 제공 CSV를 질문·답변·인용 조문·오류 유형 원문과 함께 `data/v5/qa_reasoning_val.csv`에 별도 val로 등록한다. 기존 분할과 집계에 합산하지 않는다.
- 기존 웹앱 질문 경로를 쓰는 전용 평가 명령을 제공한다. 문항별로 답변 원문, 제공 조문, 인용 조문, 응답 상태와 완료 시간을 저장한다. 기준 조문 전체 일치 여부는 제공·인용에서 각각 집계한다. 가짜 모델로 다중 조문과 거절을 포함해 검증한다.
- 승인 후 공유 서버에서 v5 기본 구성으로 30문항을 순서대로 한 번씩 평가한다. 실행 구성과 응답 원문을 보존하고 첨부 기준 답변에 비춰 핵심 결론과 조건·예외 반영을 문항별로 판정한다. 전체와 오류 유형별로 집계한다.
- 완료 기준은 기존 val·test와 분리된 입력과 평가 경로, 기본 테스트·품질 검사 통과, 승인된 실제 모델 평가 기록이다.
