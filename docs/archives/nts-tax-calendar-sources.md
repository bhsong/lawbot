# 국세청 세무일정과 검증된 공식 수집원 연결

- 국세청의 공식 연도별 세무일정 표에서 원천세·지급명세서·연말정산 관련 행을 읽고, 기한과 귀속·지급기간을 별도로 저장한다. 해당 연도 표에서 확인한 날짜만 공개하고, 조회 실패 시 마지막 정상 자료와 확인 시각을 사용한다.
- 기존 공개 스냅샷에 세무일정 필드를 추가한다. 별도 읽기 전용 조회, 월별 빨간 `세무 N` 배지와 날짜별 국세청 링크를 제공한다. 기존 법령 일정과 챗봇 수집·코퍼스 계약을 보존한다.
- 이전 시험의 고용노동부 4개, 재정경제부 개정세법, 국세청 세무일정·제출 안내를 정식 어댑터에 연결한다. 접근 규칙과 이용 범위를 대조하고 메타데이터만 보존한다. 수집원 활성화는 해당 코드가 운영에서 실행될 수 있는 시점에 적용한다.
