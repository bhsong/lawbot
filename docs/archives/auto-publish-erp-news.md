# ERP 최신 소식 자동 공개

고용노동부·재정경제부·국세청의 등록된 공식 자료원에서 제목, 게시일, 공식 원문 링크를 확인하면 최신 소식에 자동 반영한다. 검증된 자료원에만 자동 공개 기본값을 적용하고 운영자가 수집원별로 수동 검토를 선택할 수 있게 한다.

- 공개 스냅샷과 관리자 검토 목록에서 같은 공개 판정을 사용한다. 원문 링크나 메타데이터가 공개 기준을 충족하지 못하면 자동 공개 대상에서 제외한다.
- 관리자의 공개 철회와 사유를 보존한다. 철회 이후 수집된 정정판은 별도 승인 전까지 공개하지 않는다.
- 기존 자료를 최신 목록에 반영하고 보관 전용 기준선은 신규 알림에서 제외한다. 세무일정 표시, 홈택스 안내 링크, 법령 일정, ERP 업무 기준 판정·챗봇은 기존 계약을 사용한다.
- 수동 검토 회귀, 자동 공개와 정정, 철회 후 재승인, 수집원 OFF, 의심 메타데이터, 같은 일일 스냅샷의 공개 목록과 알림 변경분을 테스트한다. 운영에서는 같은 날 공개 스냅샷을 재발행하고 API를 대조한다.
