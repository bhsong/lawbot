# ERP 기관별 최신 소식

개발 기준 `bbbde46`. [통합 수집기 계획](../plans/source-hub-erp-v1.1.md)

1. 수집 자료 DB에서 정확한 리비전의 공개 검토 결정을 기록한다. 운영자가 출처·이용 조건·개인정보를 검토한 판만 공개 파일로 내보낸다. 수정판과 철회 상태를 확인하고 활성 출처, 공식 주소, 시각을 검증한다.
2. 캘린더 서버는 선택적으로 구성한 공개 소식 파일을 읽어 `GET /api/erp-news/latest`에서 기관별 10건을 제공한다. 법령정보센터는 활성 법령 범위의 기존 승인 공포 기록을 읽는다. 홈택스는 공식 홈과 자료실 경로를 제공한다. 기존 법령 API와 ERP v1, 조문 갱신은 유지한다.
3. ERP 우측에 기관 버튼 다섯 개와 단일 슬라이드 오버를 추가한다. 모바일은 하단 패널을 열고, 키보드·호버·바깥 클릭·초점 복원·감소된 모션을 지원한다. 호버 시 Lawbot API만 읽는다.
4. 검토·철회·비활성·지연·정렬·링크와 공개 필드의 계약, 기존 API 회귀 및 실제 로컬 브라우저 흐름을 검증한 뒤 PR을 올린다. 운영 소스 활성화, 외부 수집, 효력 카드와 발송은 이 PR의 개발 검증 범위 밖이다.
