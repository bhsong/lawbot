# v5.8.2 운영 반영과 신규 ERP 수집 경로 시험

2026-11-14 KST. [운영·시험 결과](../evals/2026-11-14-deploy-v5.8.2-and-erp-probe.md)

- 승인된 PR #142 병합 커밋을 운영 worktree에 반영하고 패치 태그 `v5.8.2`를 붙인다. 배포 전 캘린더 DB v8과 운영 API를 확인하고, 현재 캘린더 DB의 압축 복구본을 만든다. 최신 성공 국회 수집에 이미 등록된 법률안만 새 공개 규칙으로 처리한다. 캘린더 API, 승인 이력, ERP 스냅샷, 실행 중인 웹·모델 서비스와 정기 일정을 확인한다.
- 비활성 항목 중 신규 범위가 확인된 공식 공개 목록과 안내 페이지를 대상으로 실제 응답을 검증한다. 공개 접근·이용 조건을 대조하고 기존 네트워크 제한을 재사용한다. 제목·날짜·공식 링크 또는 확인 가능한 일정·변경 범위만 임시 환경에서 파싱한다. 첨부 다운로드·운영 수집원 활성화·외부 발송은 시험에 포함하지 않는다.
- 운영 전후와 HTTP·파싱·샘플·미검증 경로의 실제 결과를 평가 기록에 남긴다.
