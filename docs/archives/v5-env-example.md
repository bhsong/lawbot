# 기본 설정 예시를 v5로 전환

2026-11-07. 개발 예시와 기본 예시가 서로 다른 조문·임베딩을 선택하는 문제를 고친다. 기본 예시를 복사해 실행하면 v5 조문·매니페스트와 v5b 임베딩, v5 간결형·전체형 프롬프트를 선택해야 한다. 기존 리랭커·답변 모델 설정과 모델 파일 경로를 유지한다.

1. 설치 예시 검사에서 프로필, CSV·매니페스트, 모델 ID 일치, 인코딩 길이와 프롬프트를 검증한다.
2. `.env.example`에서 `LAWBOT_PROFILE=v5`와 v5b 임베딩을 지정한다. 기본 조문은 저장소의 v5 데이터를 사용한다. 운영용 live 경로는 초기화 절차에 맞춰 문서와 주석 예시로 제시한다.
3. 대역 브라우저가 기본 예시의 실제 모델 ID를 사용하도록 두 예시를 대조한다. 설치·실행 문서를 고치고 전체 기본 테스트를 검증한다.

실제 개발·운영 `.env` 변경이나 실제 모델 호출은 이 작업의 검증 범위와 분리한다.
