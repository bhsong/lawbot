# 법령 원문을 이용한 자동 근거 보강 검토

- 저장된 법률 상위 조문과 하위법령을 출발점으로 삼고, 법령 원문의 참조 관계와 정의 조항에서 보강 후보를 자동으로 찾는 규칙을 로컬에서 비교한다. 문항 ID나 기준 조문은 후보 선택에 사용하지 않는다.
- 추론 val 30문항과 저장된 일반 val 검색 결과에서 전체 기준 조문 회수, 보강 발동 수, 기준 조문 추가 수와 로컬 선택 시간을 기록한다. 기존에 기준 조문이 제공된 문항의 추가는 별도 집계한다.
- 보강이 선택되면 연결된 기존 조문 바로 뒤에 최대 2개를 배치한다. 이번 오프라인 검토에서 모델 호출, 운영 설정 변경, PR 작업은 하지 않는다. 답변 효과나 전체 지연은 실제 모델 비교에서 별도로 판단한다.
